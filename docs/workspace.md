# 全国总览与业务工作台

默认页面改为面向值守人员的日常操作界面。

- 总览默认完整全国地图，突出四川及康定。可点击四川或切换“康定现场”，继续查看道路、风险、资源和路线；随时返回全国图。地图保留下载文件的全部图形，不人为裁去省区及附属图形。
- 监测数据展示业务指标、状态、时间与来源。风险研判显示趋势和关注区域，保留数据过期提醒。
- 灾情处置使用地点、人数、增减口径、需求、道路和资源表单。智能整理只给出待审报告，人工确认后更新任务；人员不编辑JSON或查看模型内部响应。
- 资源调度使用“兼顾整体响应 / 优先紧急需求”的处置侧重。资源缺口、预计到达变化与预案原文可核对；不展示算法公式、求解状态、运行耗时或数据库信息。
- 处置记录保留确认、退回、任务调整和人数修正链，不显示后台调试日志。当前数据包含演练设定，集中保留标识。

## 实现与验收

业务接口按白名单投影字段，不向页面返回完整运行快照、数据库表、训练哈希、模型配置、求解器诊断和原始模型输出。待审报告原始上下文保存在服务端，15分钟有效、最多32条；确认使用服务端记录并检查态势变化，过期候选不能直接执行。异常详情保留在本机维护日志，用户只收到可操作提示。

默认旧研究接口、接口文档和旧页面脚本关闭。旧评测可通过本机环境变量临时启用；这不是登录或分角色授权实现。仍按已有要求本机运行，没有增加公网部署。

全国图来源：[阿里云DataV地图](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)。下载原文与哈希见 `frontend/china.json`、`data/v23/final/china-map-source.json`，仅作为全国区位展示，不参与调度寻路。康定道路背景仍来自既有OSM快照。

完整76项测试通过，包括新业务接口字段过滤、错误不泄露、旧接口关闭、候选过期和九阶段一致性。浏览器验证记录保存在 `results/workspace/`；之前的研究评测和旧版截图不覆盖。
