# 数据说明与审计

数据分为public_fact（公开事实）、public_policy_excerpt（公开预案节选）、simulated（实验设定）以及agent_authored_gold（代理设定的标注）。标签写入源文件；Task/Team运行时类不携带重复来源标签，来源继承场景级标记。

## 真实案例

`case_facts.json` 保存四条结构化记录：灾害与道路中断、转移安置、伤亡分项、救援资源汇总。每条含event_time、published_at、source_id、url、summary、evidence_excerpt、source_locator与values。event_time未知时为null，不从发布时间推测。

新华社2024-08-04 21:39:21报道提及8月3日和4日不同时间点，因此历史可见性按发布时间筛选，不按事件时间提前泄露。两个分项遇难/失联合计来自人工结构化，保留原分项描述以便核对。当前康定政府网页正文部分以图片呈现，列作交叉参考；主要可检索事实来自新华社正文，不声称完成图片通报人工录入。

## 预案

两份灾害前已发布版本，共20条节选。字段包括id、source_id、section、text、title、version、published_at、url、verification、scope。节选只去除PDF换行，不补写政策。国家一级响应措施仅作特定范围知识，不能当作康定实际启动等级的证明。

检索是字符2—4 gram TF-IDF、余弦相似度前五，应用公开时间过滤；候选能力使用固定任务模板词扩展查询，将“被困”等口语连接到“人员搜救”等预案用语。不包含训练、向量服务或法律适用性自动判断。搜索索引核验与原文下载核验有不同状态，界面和数据保留差异。

## 模拟场景

- 10个节点：id、name、x、y；平面示意坐标不是地理坐标。
- 16条双向道路：u、v、minutes；封路只改变通行性，不更改基础边权。
- 8支队伍：id、capability、node、available_at；6支初始可用，2支由第40分钟事件激活。
- 12项任务、14个需求单位：id、node、capability、required、priority、deadline、duration、release、description、citations。
- 四阶段事件在0、5、20、40分钟发生，模拟截止180分钟。参数不是实际救援规模的缩放。

实验标准场景seed=-1，另外seed=0…19。扰动独立改变路程0.75—1.35倍、作业时长0.75—1.4倍、需求数量-1/0/0/+1并限制在1—3。所有算法读取同一份扰动文件，随机化不按方法分叉。

## 文本标注与缓存

20条样例由代理人工设定标签，覆盖三类能力和十个已知地点；不是外部独立标注或泛化测试集。每条另设支持任务类型的条款ID集，计算条款Recall@5和引用命中精度；该人工小集不能证明法规适用性。非空合法引用覆盖率与文档Recall@5不可称为语义准确率。真实API结果单独输出，离线规则和缓存绝不算模型成功调用。

缓存仅匹配完整原文，保存固定示例及来源说明；不会把模糊匹配的其他灾情伪装成已核对结果。生产化所需的多地点、多任务、来源冲突和实体链接超出此版。
